Welcome to Plotbunny 💧

A writing-community toolkit for Discord: prompts, writing sprints, challenges, projects, goals, and community tools for writers.

Early development. The rabbit is still building the shelves.

☕🌙 Midnight Coffeehouse Roadmap

Plotbunny exists because the Coffeehouse needs it.

🚪 Phase 1 — Open the Doors 📍 Current

  • ⬜ Finish server structure
  • ⬜ Finalize rules & guidelines
  • ⬜ Finish onboarding
  • ⬜ Set up introductions and community spaces
  • ⬜ Set up writing discussion and sharing spaces
  • ⬜ Set up book/media discussion
  • ⬜ Invite our first members

Goal: Make Midnight Coffeehouse feel like somewhere people actually want to hang out.

☕ Phase 2 — Find Our Rhythm 🔜 Next

  • ⬜ Regular writing sprints
  • ⬜ Casual writing sessions
  • ⬜ Writing discussions and prompt sharing
  • ⬜ Book discussions
  • ⬜ Community events
  • ⬜ Low-pressure challenges
  • ⬜ Listen to member feedback and adjust the server

Goal: Build community traditions, not a giant schedule nobody uses.

🐇 Phase 3 — Bring in the Plotbunny 🔧 In Development

  • ⬜ Deploy Plotbunny to Midnight Coffeehouse
  • ⬜ Writing prompts
  • ⬜ Writing sprints
  • ⬜ Challenges
  • ⬜ Project tracking
  • ⬜ Writing goals
  • ⬜ XP & awards
  • ⬜ Server-specific configuration
  • ⬜ Test features with Coffeehouse members
  • ⬜ Gather feedback and fix what doesn't work

Goal: Build tools that are actually useful to our writers.

🧁 Phase 4 — Grow the Coffeehouse 🌱 Later

  • ⬜ Recurring events
  • ⬜ Seasonal challenges
  • ⬜ Community writing projects
  • ⬜ Themed events
  • ⬜ Member-led activities
  • ⬜ Optional achievements
  • ⬜ Community traditions
  • ⬜ Refine onboarding as we grow

Goal: Let the community develop its own culture.

📚 Phase 5 — Build the Bookshelf 🌐 Future

  • ⬜ Launch the Plotbunny website
  • ⬜ Document the bot
  • ⬜ Create challenge & sprint guides
  • ⬜ Create self-hosting documentation
  • ⬜ Organize community resources
  • ⬜ Add the interactive bookshelf
  • ⬜ Establish Midnight Coffeehouse as Plotbunny's home community

Goal: Make our resources easy to find, use, and share.

🌎 Phase 6 — Share What We've Learned 🐣 Someday

  • ⬜ Invite other writing communities to try Plotbunny
  • ⬜ Gather outside feedback
  • ⬜ Identify what should become general-purpose
  • ⬜ Improve configuration and documentation
  • ⬜ Support self-hosting
  • ⬜ Consider public releases

Goal: Let Plotbunny grow organically from something we needed into something other writing communities might find useful.

☕ The Coffeehouse Rule

Midnight Coffeehouse comes first.

Plotbunny exists because this community needed better tools. The Coffeehouse isn't a test audience for a pre-existing product. It's the community the tools are being built for.

We'll build the Coffeehouse first, listen to the people who use it, and let the bot grow alongside the community.

No feature exists just because we can build it.

🐢 Slow growth is still growth.
🐇 And occasionally, a plotbunny runs off with an idea.
🐇 Mind the hares. 🐢 Follow the tortoise. 📚 Write the story.
