# 🐇 plbunny

**A prompt-based writing bot for Discord, with a callback to the plot bunnies of olde and the legacy of `fanfic_bakeoff`.**

> *Mind the hares.*

plbunny is a Discord bot for writing communities, built around scheduled writing prompts, creative challenges, and the inevitable runaway plot bunny.

It is designed for **both original fiction and fanworks**. The prompt is the common ground; what you do with it is up to you.

---

## ✍️ What is plbunny?

plbunny delivers writing prompts and challenges directly to Discord communities.

The goal is to make it easy for a writing group to say:

> "Here's something to write about. Go forth and make words."

Whether that means a 500-word flash fiction piece, a 100,000-word novel that absolutely was *not* supposed to happen, a fanfic, a poem, or something nobody can quite categorize is entirely up to the writer.

### Planned features

* 🐇 Scheduled general writing prompts
* 🎲 On-demand random prompts
* 🧁 Bakeoff-style writing challenges
* 📅 Challenge opening and closing dates
* ⏰ Automatic challenge reminders
* 📚 Prompt and challenge archives
* 💡 Community-submitted prompts
* 🛠️ Discord-based configuration
* 🌎 Per-server schedules and settings
* 📝 Support for both original fiction and fanworks
* 🏠 Self-hosting support
* 🔌 Configurable prompt libraries

---

## 🧁 Inspired by the old internet

plbunny is a little love letter to two pieces of writing-community culture.

### Plot bunnies

A **plot bunny** is a story idea that appears out of nowhere, demands to be written, and frequently reproduces while you're trying to work on something else.

Sometimes you catch one.

Sometimes the hares get away from you.

### `fanfic_bakeoff`

The challenge system takes inspiration from the old **`fanfic_bakeoff`** community tradition: give writers a collection of ingredients, constraints, or prompts and see what they bake.

plbunny carries that idea beyond fandom.

**Original fiction and fanworks are equally welcome.**

## 🚧 Project Status

**Current status: Early development**

plbunny is currently being developed and tested within a small writing community.

The repository is public, but the bot is **not yet ready for general installation**.

The development plan is roughly:

1. Build the core bot
2. Test it in a real Discord community
3. Refine the prompt and challenge systems
4. Make server configuration more flexible
5. Document self-hosting
6. Release plbunny publicly

Features and architecture may change substantially during development.

---

## 🛠️ Planned Technology

The initial implementation is planned around:

* **Python**
* **discord.py**
* **SQLite**
* **Discord Application Commands / Slash Commands**

The project is being designed so that individual Discord servers can configure their own schedules, channels, prompt libraries, and challenges without requiring changes to the bot's source code.

---

## 🏠 Self-Hosting

Once plbunny reaches its public release, communities will be able to run their own instance.

A self-hosted installation will be able to use:

* Its own Discord application
* Its own bot token
* Its own prompt library
* Its own schedules
* Its own server configuration
* Its own database

The goal is for communities to be able to customize plbunny without having to maintain a heavily modified fork.

Self-hosting documentation will be added as the project approaches public release.

## 🐇 Why "plbunny"?

Because sometimes you sit down intending to write one story.

Then another idea appears.

And another.

And another.

And suddenly there are seventeen tabs open, three unfinished documents, two worldbuilding notebooks, and a suspiciously detailed history for a character who was supposed to have one line.

**Mind the hares.**
